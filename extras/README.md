# Extras

Optional, hardware-specific pieces that are **not** installed by default.

* `fingerprint-dualboot/` — keep Windows Hello fingerprints when enrolling on Linux (match-on-chip readers).

Not included on purpose (they contain proprietary vendor data or are tied to one machine):
Samsung Galaxy Book MAX98390 speaker tuning tables and Dolby presets, camera relay, personal
backup scripts. See `docs/INVENTORY.md`.
