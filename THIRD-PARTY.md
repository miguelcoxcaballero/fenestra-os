## What Fenestra does **not** contain

Fenestra is not affiliated with or endorsed by Microsoft. "Windows" is a trademark of
Microsoft Corporation and is only used here to describe compatibility of look and feel.

The repository does **not** include any file taken from a Windows installation:
no Segoe UI / Segoe Fluent Icons / Consolas fonts, no glyphs drawn from them, no
images from `imageres.dll`/`shell32.dll`, no Windows cursors, wallpapers, sounds,
Spotlight images or Windows Hello animations. Open replacements are generated by
`tools/generate-assets.py` or downloaded from the projects above.

Users who own a Windows installation on the same PC can run
`fenestra-import-windows-assets`, which copies their own licensed fonts, cursors,
battery glyphs and folder icons into their home directory only.
